このアプリについて

居酒屋で日本酒を選ぶときの迷いを減らすため、味わいの傾向から銘柄を探せるようにしました。銘柄の味は商品や提供温度で変わるため、説明は選ぶときの目安です。

お酒は20歳になってから。飲酒運転は法律で禁じられています。体調に合わせて適量を楽しみましょう。
